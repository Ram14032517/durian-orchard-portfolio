# ชั้นขอบเขตชุดดิน

ข้อมูลกรมพัฒนาที่ดิน ปีผลิต 2561 มาตราส่วนต้นฉบับ 1:25,000 แปลงเป็น WGS84 และลดรายละเอียดเส้น 50 เมตรสำหรับแสดงผลเท่านั้น ไม่ใช้คำนวณพื้นที่หรือระบุแนวเขตแปลง

สุราษฎร์ธานี (84): ดาวน์โหลด 23 กันยายน 2569 จาก https://tswc.ldd.go.th/DownloadGIS/web_Soil/SoilSeries/S/sr_sni.rar

SHA256 ของ archive: `62063a8636845d941027a35fd9c969a7a3adc4f04b75eada79ebad4a192bb79d`

ตรวจปีผลิต มาตราส่วน และ WGS1984 UTM Zone 47N จากไฟล์ ReadMe ใน archive แล้ว ขอบเขตนี้เป็นชุดดินทั้งจังหวัด ยังไม่ได้ซ้อนพื้นที่ปลูกทุเรียน A403 ของสุราษฎร์ธานี และยังไม่ได้ระบุชุดดิน ณ จุดติดตั้งเซนเซอร์ของผู้ใช้

แหล่งข้อมูลอีก 4 จังหวัดอ้างอิง `research_data/regional_orchards/SOURCE_TH.md` โค้ดแปลง: `tools/build_soil_map_layers.py`
