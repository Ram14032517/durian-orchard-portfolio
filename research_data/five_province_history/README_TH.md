แนะนำให้ใช้เซิร์ฟเวอร์ข้างต้นสำหรับอากาศตามจุดที่เลือกผ่าน `/api/weather` หาก API ใช้ไม่ได้ หน้ารวมจะใช้ cache จุดเดิมที่ตรวจ SHA256 แล้ว หรืออ่านไฟล์ `daily_<รหัสจังหวัด>.json` ที่ครอบคลุมช่วงวันที่ หากเลือกอำเภอ/หน่วยดินแล้วต้องใช้จุดอ้างอิงจังหวัดแทน จะขึ้นคำเตือนว่าพิกัดข้อมูลต่างจากพิกัดที่เลือก ข้อมูลสำรองนี้ไม่ใช่อากาศรายแปลง ต้องเปิดผ่าน localhost เพื่ออ่านไฟล์ JSON; การเปิด HTML ตรง ๆ อาจไม่ทำงาน ต้องต่ออินเทอร์เน็ตสำหรับแผนที่พื้นหลังและการดึงอากาศใหม่ ไม่ต้องล็อกอิน GitHub เพื่อรันในเครื่อง

เลือกพื้นที่ A → กดใช้เป็น B → เลือกพื้นที่ A อีกแห่ง → เลือกเดือนหรือช่วงวัน → กดดูอากาศ ค่าจะถูกล้างเมื่อเปลี่ยนวัน/พื้นที่เพื่อไม่ให้สับสนกับผลครั้งก่อน พิกัดอำเภอเป็นจุดอ้างอิงจากแผนที่ดิน ไม่ใช่สวนที่ยืนยันแล้ว อากาศกริดอาจเหมือนกันสำหรับพื้นที่ใกล้กัน

ใช้เมนูทางลัดด้านบนไปยังเดือน พื้นที่ กราฟ ผลผลิต หรือข้อมูลเทรนได้ทันที ปุ่ม **ดูกราฟอากาศเดือนนี้** โหลดเดือนรายงานที่เลือก; ในกราฟเปลี่ยนตัวแปรได้ 7 ค่า และกดดาวน์โหลดอากาศ A/B เป็น CSV ได้หลังโหลดสำเร็จ CSV เก็บพิกัดที่เลือก พิกัดข้อมูลจริง สถานะแหล่งข้อมูล หน่วยเวลา LST และคำเตือนสำหรับใช้วิเคราะห์ต่อ เมนู **5 ข้อมูลเทรน** รวม CSV รายเดือน/รายปี จำนวนแถว และคู่มือ Jupyter ไว้จุดเดียว

## ข้อมูลจริงที่รวบรวม

- NASA POWER daily ณ จุดอ้างอิงจังหวัด 5 จุด: จันทบุรี ชุมพร ศรีสะเกษ อุตรดิตถ์ สุราษฎร์ธานี
- อุณหภูมิ/ฝน/ความชื้น/ลม: 1981-01-01 ถึง 2026-09-22; แสง: 1984-01-01 ถึง 2026-09-20 ในการดึงรอบ 26 กันยายน 2569
- วันแบบ Local Solar Time (LST) ไม่ใช่การยืนยันขอบเขตวันสถานีไทย เวลาเกิดเหตุรายชั่วโมงต้องตรวจแหล่งเพิ่ม
- ผลผลิต OAE รายปี 1997–2025: 145 จังหวัด–ปี รายเดือนใช้ระเบียนต้นทางที่มี (ไม่เติมเดือนที่ไม่มีแถวเป็นศูนย์)
- เก็บ raw NASA พร้อม URL เวลาและ SHA256 ใน raw/; ค่าหาย -999 แปลงเป็น missing

## ตอบคำถามได้ระดับไหน

เลือกช่วงวันเพื่อดูอากาศกริด และเปรียบเทียบผลผลิตจังหวัด/ผลผลิตต่อไร่ระหว่างปีได้ ยังไม่มีวันที่ทำใบ ดอกบาน ผลอ่อน และจำนวนร่วงรายสวนครบทุกปี และยังไม่ได้ดึงอากาศรายอำเภอหรือรายชุดดิน

หน้ารวมส่วน 2 เลือกกราฟ A/B ได้ 7 ค่า: อุณหภูมิเฉลี่ย/สูงสุด/ต่ำสุด ฝน ความชื้นอากาศ รังสีดวงอาทิตย์ และลมเฉลี่ย วันขาดค่าจะเว้นช่วงกราฟ เมื่อช่วงยาวกว่า 62 วันกราฟรวมเป็นรายเดือน (ฝนรวม; ค่าสูงสุด/ต่ำสุดใช้ค่าสุดขั้ว; ค่าอื่นเฉลี่ย) ต้องกด “ดูอากาศ” หลังเปลี่ยนจุดหรือวัน แต่การสลับตัวแปรกราฟใช้ข้อมูลที่โหลดแล้ว

หาก API ตอบผิดพลาดหรือไม่ได้ JSON (เช่น HTTP 403) หน้ารวมอ่านไฟล์ NASA POWER รายวัน ณ **จุดอ้างอิงจังหวัด** ที่เก็บไว้แทน พร้อมแถบเตือนพิกัดต้นทางและพิกัด A/B; ค่านี้ไม่ใช่อากาศตรงอำเภอหรือหน่วยดินที่คลิก ห้ามใช้สรุปความแตกต่างรายแปลง หากเซิร์ฟเวอร์เคยบันทึกคำขอพิกัดเดียวกันไว้และ NASA ไม่พร้อม จะใช้ cache ที่ตรวจ SHA256 ผ่าน พร้อมระบุว่าไม่ได้อัปเดต หากไม่มีข้อมูลสำรองครอบคลุมวันที่เลือกจะแจ้งผิดพลาด ไม่สร้างข้อมูลขึ้นมาเอง

ส่วน 4 แสดงพื้นที่ให้ผลและผลผลิตต่อไร่ข้างยอดรวม พร้อมอากาศ 6 เดือนก่อนเดือนเก็บเกี่ยวอ้างอิงของปีที่เลือกเทียบปีก่อน ผลโมเดลรายปีสร้างซ้ำด้วย `python tools/compare_annual_yield_features.py` จาก panel ที่สร้างโดย `tools/analyze_annual_yield_windows.py`; รายละเอียดและข้อจำกัดใน `training/README_TH.md` และ `training/annual_yield_feature_comparison.json` ค่าอากาศเป็นจุดอ้างอิงจังหวัด ไม่ใช่ค่าของ polygon ชุดดินที่คลิก

เครื่องมือนับย้อนใช้สูตร เก็บเกี่ยวแรก−อายุผลสูงสุด ถึง เก็บเกี่ยวสุดท้าย−อายุผลต่ำสุด ค่า 120–140 วันเป็น scenario ที่แก้ไขได้ ต้องยืนยันพันธุ์ อายุเก็บเกี่ยว และวันที่จริงก่อนใช้สรุปผล ช่วงฟื้นต้น/ทำใบไม่สามารถอนุมานวันที่แน่นอนจากวันเก็บเกี่ยวเพียงอย่างเดียว

ยอดผลผลิตรวมลดลงอาจเกี่ยวข้องกับพื้นที่ให้ผล จึงแสดงผลผลิตต่อไร่และพื้นที่ให้ผลคู่กัน ไม่แจกยอดจังหวัดลงสวน/อำเภอ/ชุดดิน และไม่อ้างว่าอุณหภูมิเป็นสาเหตุจากความสัมพันธ์เพียงอย่างเดียว ลมเฉลี่ยรายวันไม่ใช่ความเร็วลมกระโชกในพายุ
